    Standard InSinkErator Installation in Evanston

    A standard install goes into a sink that already has a drain and power. We take the old disposal down, scrape the old putty off the flange and set a new flange with fresh putty.     Nearly every InSinkErator has a dishwasher inlet with a factory knockout plug inside. The plug gets knocked loose and pulled out of the grind chamber.
