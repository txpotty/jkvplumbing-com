    Disposal Installation in Evanston, WY: How We Do It

    Same-Day Disposal Installation in Evanston, WY

    When the old disposal dies and the sink is full of water, we can usually install a new one the same day. Our trucks carry common 1/2 and 3/4 HP models, mounting hardware and cord kits, so we do not need a second trip to the supply house before the sink drains again. Figure on roughly an hour.

    Disposal Upgrades in Evanston, WY

    Stepping up from an old 1/3 HP unit to a quieter model is a common request. We disconnect and remove the old disposal, check the trap and drain arm for corrosion, and install the new unit with a new mount, so the upgrade does not inherit the old unit's worn parts. Old drain arms often need replacing. Rust works from inside galvanized pipe.

    Disposal Rough-In for New Construction in Evanston

    At rough-in we set the drain height and the outlet location before the cabinets go in. For a kitchen with a disposal, we usually set the drain stub lower than a plain sink would need, so the trap can sit below the disposal outlet with room for proper fall. The electrician adds the switched outlet. We mark its spot so it clears the trap.

    Switching From Batch-Feed to Continuous-Feed in Evanston, WY

    A continuous-feed unit needs a switch, which a batch-feed kitchen may not have. That can be a wall switch, an air switch button on the sink deck or a switched outlet under the sink, and the choice depends on how hard it is to run wire to the spot you want. Air switches avoid new wiring in the wall. The drain usually stays the same.

    Disposal Installation on an Existing Sink in Evanston

    With a typical 1/2 or 3/4 HP unit, we remove the old unit if there is one and install the new one on the existing sink. We connect it to the drain, set the P-trap and wire it, then check the clearance under the sink, which can be tight in older Evanston homes with shallow cabinets or a water filter mounted on the back wall. Tight cabinets need planning. A compact unit can solve it.

    Batch-Feed Units for Kitchens Without a Switch in Evanston

    These disposals run only with the stopper lid seated, which adds safety for families with kids. They need no wall switch, so they are a good choice for kitchens where adding a switch would mean cutting into finished drywall or tile backsplash. The drain hookup is the usual setup.

    First-Time Disposal Installation in Evanston

    For kitchens that have never had a disposal, we start by checking the sink flange, drain height and electrical supply. The mount goes on, the unit gets hung and the discharge tube is connected to a new trap, with the wall stub lowered if it sits too high. Power comes from a licensed electrician when needed.

    InSinkErator Model Selection in Evanston, WY

    We help you pick between the Badger and Evolution lines based on how you cook, how much noise bothers you and how much cabinet room you have. Badger units are compact and simple, while Evolution units are taller and heavier, with more grind stages and better sound insulation. The cabinet usually settles it. Measure first, then buy.
